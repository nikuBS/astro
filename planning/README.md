## 데모 실행

GitHub는 HTML 파일을 소스 코드로만 보여줍니다. 아래 중 하나로 실행하세요.

- 파일을 내려받아 브라우저로 열기: `demo/index.html` 한 파일이면 됩니다 (인터넷 연결 시 폰트 적용).
- 저장소를 받은 경우:

```bash
open planning/demo/index.html
```

## 데모 구성

- **왼쪽, 작성자 에디터**: 장르 선택 → 내용(이름·일시·장소·대사·사진) → 캐릭터 → 발행
- **오른쪽, 하객 화면**: 청첩장(정보·송금·이벤트·갤러리·방명록) → 대화 → 미니게임 → 랭킹
- **미니게임**: 용사 방어전(무료 슈팅), 마왕성 보스전(턴제 RPG), 부케 포격 작전(포격), 웨딩로드 질주(레이싱). 물풍선 미로·사진 블록 퍼즐은 COMING SOON
- 하객 화면은 예식 정보가 먼저 나오고, 게임은 "도전 이벤트"로 원하는 하객만 참여
- 요금제: 무료(15일, 기본 슈팅·사진 3장) · 45일 패키지 2,900원 · 90일 패키지 4,900원(전체 장르·랭킹·방명록·사진첩)
- 발행 시 구글 로그인 화면(데모용, 실제 로그인 없음)
- 저장 기능은 없습니다. 새로고침하면 처음 상태로 돌아갑니다.

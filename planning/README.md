레트로 게임 모바일 청첩장 서비스 전환을 위한 기획·설계 자료입니다.

| 자료 | 위치 | 설명 |
|---|---|---|
| 기술 설계 문서 v0.1 | [tech-design-v0.1.md](tech-design-v0.1.md) | 아키텍처, 데이터 모델, 게임 런타임, 보안, 일정 매핑 |
| 투자자 데모 | [demo/index.html](demo/index.html) | 작성자 에디터 + 하객 청첩장, 플레이 가능한 미니게임 3종 |

## 데모 실행

GitHub는 HTML 파일을 소스 코드로만 보여줍니다. 아래 중 하나로 실행하세요.

- 파일을 내려받아 브라우저로 열기: `demo/index.html` 한 파일이면 됩니다 (인터넷 연결 시 폰트 적용).
- 저장소를 받은 경우:

```bash
open planning/demo/index.html
```

## 데모 구성

- **왼쪽, 작성자 에디터**: 장르 선택 → 내용(이름·일시·장소·대사·사진) → 캐릭터 → 발행
- **오른쪽, 하객 화면**: 타이틀 → 대화 → 미니게임 → 초대장 카드 → 엔딩(갤러리·송금·방명록)
- **미니게임**: 마왕성 보스전(턴제 RPG), 부케 포격 작전(포격), 웨딩로드 질주(레이싱). 물풍선 미로·사진 블록 퍼즐은 COMING SOON
- 3번 실패하면 자동 통과, 상단 "정보 바로 보기"로 언제든 예식 정보 확인
- 저장 기능은 없습니다. 새로고침하면 처음 상태로 돌아갑니다.
